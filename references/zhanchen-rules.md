# 展陈文本参考手册

源自策展小兵与策划大师对攀枝花、湖南人、水口山、渌江书院四组文本的整理；原始记录日期2026-04-20，2026-05-11合并，2026-09-07区分案例手法与交付约束。按当前任务选择以下内容。

## 文体参考

| 文体 | 适用参考 | 表达方法 | 使用边界 |
|---|---|---|---|
| 纪念碑铭体 | 工业遗址、战争与革命记忆 | 准确年代和事实、克制情感、陈述与短排比 | 需庄重时使用；不强制小数、领导引文或诗意标题 |
| 人类学叙事体 | 地域文明、民族史、非遗 | 现象—溯源—意义，平实亲和，必要文献注释 | 根据研究和观众选择，不强制每段三段式 |
| 史志政论体 | 企业史、产业、成就、党建 | 事实与政策语境、具体案例、适度排比 | 四字格、救国—报国—强国只是历史写法；无依据不用第一或首创 |
| 书院诗意体 | 书院、教育、人物与文脉 | 诗词意境、以人带史、建筑与历史交融 | 山长—名流—英才等人物分组按资料实际调整 |

例子：“弦歌不辍”“斯文在兹”可启发书院标题；“初心如磐”“薪火相传”是历史常见表达，不作为默认答案。社区类优先居民体验、具体服务和真实案例，避免术语堆砌。

## 完整项目可选工作顺序

明确主题与观众 → 收集资料 → 约定凡例与编号 → 建立叙事 → 逐层撰写 → 事实和表达核对 → 需要时内部评审与设计对接 → 交付。

已有资料和成果可以复用、合并步骤。常见骨架为序厅点题、主体展开、特展聚焦、尾厅回应；主体单元数量由内容和空间决定，不强制3—4个。社区的历史沿革、党建引领、为民服务、未来愿景是可选组织方式，不要求每次齐全。

## 凡例与展品信息

以下是设计工作稿的既有标签方案，仅在需要此类交付且甲方未指定其他方案时使用。面向观众的最终文案不强塞编辑标记。

| 标签 | 用途 |
|---|---|
| 【文物】【模型】【图片】【表】【文献】 | 实物、模型、图像、图表和文献资料，既有色系为橙色 |
| 【多媒体】 | 视频、音频或互动，既有色系为红色 |
| 【说明】 | 面向观众的客观说明 |
| 【设计思路】【设计建议】 | 对应展项的设计说明，既有色系为蓝色 |
| 【解说词】 | 导览讲解文本 |

展品条目按实际资料填写：名称、时代、尺寸及单位、来源（征集/复制/借展等）、收藏单位、客观说明。未知字段标待补，不补造；非实物展项不强填实物尺寸或收藏单位。

新编完整项目且无既定要求时可采用：展厅“一、二、三”、单元“1. 2. 3.”、展项“(1) (2) (3)”、展品使用能追溯父级的连续编号。四级映射需要清楚一致。现有项目保留原编号体系，增删仅调整受影响部分。

既有项目常用参考字数：前言不超过300字、单元前言150字、展品说明200字、结语100字；根据阅读距离、版面和客户要求调整，不当作所有载体的上限。

## 句式工具箱

仅在事实与文风相符时参考，不按模板填不存在的信息：

- 定义：主体是在某一背景下形成的某类事物。
- 历史节点：某年发生某事，带来可验证的变化。
- 文献引用：《文献名》中的已核实原句，附出处与必要语境。
- 数据：在明确时间和统计口径内完成某项工作，标明来源。
- 结语：回应主题，并以具体的当下连接结束。

领导引文须核对原文、人物、年份及场合；成就句只有在范围与证据都支持时使用“第一/首创”。不因句式需要而制造统计口径、历史意义或情绪。

## 四个案例的学习用途

| 项目 | 可借鉴之处 | 不直接迁移的内容 |
|---|---|---|
| 攀枝花工业 | 三线建设叙事、工业精神、克制事实表达 | 未核验数字、具体引文与历史结论 |
| 湖南人文化 | 学术叙事、引用、资料组织与凡例 | 本项目的具体文化判断和展品信息 |
| 水口山矿史 | 企业史节奏、产业与社会关系、党建融入 | 对其他企业的首创/首位主张 |
| 渌江书院 | 诗意标题、人物群像、空间叙事 | 其他场所不具备的人物与建筑关系 |

## 核对要点

事实有依据、数字精度忠于来源、引文已核、语气适合观众；结构完整性按当前交付范围判断。需要设计对接时核对每条建议是否有对应展项和条件。新的复盘记录注明项目、场景、证据和适用范围；未知原材料来源时明确未随库提供，不声称已再次核实。
