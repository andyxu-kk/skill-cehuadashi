## 二、四种文体核心要点（参考细节）

### 纪念碑铭体
- **标题诗意化**：诗词/典故标题统领叙事
- **句式模板**：背景句/定义句/数据句/成就句四连

### 人类学叙事体
- **标记色系**：🟠橙色=实物展品 / 🔵蓝色=设计元素 / 🔴红色=多媒体装置
- **凡例模板**：【文物】【说明】【设计思路】【设计建议】四件套

### 史志政论体
- **叙事结构**：救国 → 报国 → 强国
- **人称切换**：「我们」+ 第三人称客观叙述混合

### 书院诗意体
- **人物群像三级体系**：山长 → 名流 → 英才
- **空间叙事**：以书院建筑空间为轴线串联历史

## 三、编号规则（详细版）

展陈文本编号必须严格遵循三级体系：

| 级别 | 格式 | 示例 |
|------|------|------|
| 展厅（一级） | 汉字：一、二、三…… | 一、 |
| 单元（二级） | 阿拉伯数字+点：1. 2. 3. | 1. 2. 3. |
| 展项（三级） | 括号阿拉伯数字：(1) (2) (3) | (1) (2) (3) |
| 展品（四级） | 展项编号+.+数字 | 1.2.3.1 / 1.2.3.2 |

> ⚠️ 禁止跳号，禁止混用编号格式

## 四、质量检查清单（完整版）

### 内容层面
- [ ] 数据精确到小数点？
- [ ] 引文标注来源？
- [ ] 历史事实有据可查？
- [ ] 年代准确无误？

### 结构层面
- [ ] 凡例完整？
- [ ] 编号规范（一级汉字/阿拉伯数字/括号三级）？
- [ ] 标题凝练（四字/诗词）？
- [ ] 段落起承转合？

### 文体层面
- [ ] 人称统一？
- [ ] 语气符合主题？
- [ ] 情感克制有度？

### 设计对接
- [ ] 【设计思路】清晰？
- [ ] 【设计建议】可执行？
- [ ] 标记色系规范？
- [ ] 展品信息完整？

## 五、九步创作工作流（详细版）

```
1. 确定主题  → 选择文体
2. 收集资料  → 档案/地方志/田野调查
3. 编制凡例  → 标签系统/色系规范/编号体系
4. 构建框架  → 序厅→主体→特展→尾厅
5. 撰写初稿  → 按单元逐级展开
6. 质量检查  → 对照清单核查
7. 内部评审  → 考据核实/文体校准
8. 对接设计  → 将文本转译为视觉语言
9. 定稿交付
```
